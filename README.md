# encanto-ticket
Projeto prático para a etapa do processo seletivo da Encanto Telecom. 

# Facilidades
Durante o desenvolvimento do Frontend em React, notei familiaridade com frameworks que trabalhei no passado
Além disso, é muito interessante a forma como o React facilita a componentização das views.

Apliquei para esse projeto a estrutura orientada à Features, onde se dá destaque para as features a serem desenvolvidas.
Pelo projeto ser pequeno em features

Nest.js possui uma certa semelhança com a criação e definição de rotas e lógica comparado ao Java Springboot.

# Problemas e Bugs
Na instalação do Docker, encontrei muitos problemas de permisão ao acesso de pastas internas do computador. Utilizando o auxílio de IA para resolver, a instalação e setup do Docker foi bem-sucedido

Jest não veio configurado corretamente. Arquivos de teste automaticamente gerados pelo Nest.js quebraram. Precisei criar "tsconfig.specs.json" na root e adicionar tipos de compilação no "tsconfig.json"
